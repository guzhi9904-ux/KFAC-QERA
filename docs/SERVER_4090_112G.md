# RTX 4090 24GB / 112GB RAM 运行配置

## 当前资源结论

- 推荐先跑 `Qwen/Qwen2.5-1.5B-Instruct`，确认全部流程后再跑 `Qwen/Qwen2.5-7B-Instruct`。
- `deepseek-ai/DeepSeek-R1-Distill-Qwen-1.5B` 和 `7B` 使用兼容的 Qwen 投影命名，但必须使用各自独立的 `RUN_DIR`。
- `meta-llama/Llama-2-7b` 可由相同的投影自动发现逻辑处理；当前缓存中没有 Llama 3。
- `Qwen/Qwen2.5-14B-Instruct` 的 BF16 权重本身已超过 24GB。当前实现把完整模型放在单张 GPU，不应在这台机器上直接运行 14B。
- WikiText-2 已缓存；C4 未出现在当前 Hugging Face cache 中。C4 评测前必须联网生成冻结窗口，或提供 `datasets.save_to_disk()` 生成的本地 validation 数据。

## 环境变量

```bash
cd KFAC-QERA
source .venv/bin/activate

export HF_HOME=/share/home/tm902089733300000/a913520780/chengkang/huggingface_cache
export HF_HUB_CACHE="$HF_HOME/hub"
export HF_DATASETS_CACHE="$HF_HOME/datasets"
export HF_HUB_OFFLINE=1
export TRANSFORMERS_OFFLINE=1
export HF_DATASETS_OFFLINE=1

export MODEL_PATH=Qwen/Qwen2.5-1.5B-Instruct
export RUN_DIR=/share/home/tm902089733300000/a913520780/chengkang/qera_runs/qwen2.5-1.5b-smoke
export CONFIG=configs/rtx4090_112g_smoke.yaml
export RUN_C4=0

bash scripts/run_4090_112g.sh
```

`MODEL_PATH` 可以直接写缓存中的 Hugging Face repo id，不需要查找 snapshot 哈希目录。

## 补充 C4

有网络时，在同一 `RUN_DIR` 中只准备 C4：

```bash
export HF_DATASETS_OFFLINE=0
qera-exp --config "$CONFIG" prepare-data --role c4
qera-exp --config "$CONFIG" evaluate --dataset c4
qera-exp --config "$CONFIG" analyze
```

若计算节点始终离线，在联网节点将 C4 validation 保存为 Hugging Face Dataset，再将配置中的 `data.c4.local_path` 指向该目录。不要把 Arrow 缓存目录直接当作 `load_from_disk()` 目录。

## Full run

Smoke 通过后使用新目录：

```bash
export MODEL_PATH=Qwen/Qwen2.5-7B-Instruct
export RUN_DIR=/share/home/tm902089733300000/a913520780/chengkang/qera_runs/qwen2.5-7b-full
export CONFIG=configs/rtx4090_112g_full.yaml
export RUN_C4=1

bash scripts/run_4090_112g.sh
```

Full 配置使用 48GiB accumulator 分片。其余内存留给 CPU-offloaded autograd tensors、Cholesky workspace、文件页缓存和运行时开销。完整 A/G 使用 FP64 保存，位于：

```text
$RUN_DIR/statistics/raw/*.safetensors
$RUN_DIR/statistics/raw/*.json
```

默认不会在 solve 后删除。每个模型的最终占用以 `plan` 输出为准：

```bash
python -c 'import json,os; p=json.load(open(os.path.join(os.environ["RUN_DIR"],"state/shard_plan.json"))); print("raw GiB:",p["estimated_retained_raw_statistics_bytes"]/2**30,"free GiB:",p["disk_free_bytes_at_plan"]/2**30)'
du -sh "$RUN_DIR/statistics/raw" "$RUN_DIR/corrections" "$RUN_DIR/evaluation"
```

不要读取或提交 Hugging Face cache 根目录中的 `token`、`stored_tokens`。
