# QER 第一步：固定左右几何，比较误差 SVD 与真实梯度 SVD

版本：v1.0，2026-09-19。

状态：**实验设计文档；尚未实现、部署或执行。本次不启动服务器任务。**

## 1. 本轮回答什么

> 固定已有 Marginal-AG 的左右几何，把 SVD 输入从白化误差换成该几何下的真实 functional gradient，能否产生收益更高的低秩补偿？整体幅度校准能否解释两者的差异？

第一步不学习新的 A/G，不要求证明全局低秩最优，也不先解决候选空间覆盖、完整 restricted whitening 或所有 rank 的共同最优性。

核心变化只有一项：**SVD 的输入**。对两种输入都同时保留原始幅度和同规则的标量校准，区分方向选择与幅度失配。

## 2. 对理论总结的审计

### 2.1 三条结论及准确边界

1. 给定正定 separable 二次项，保留真实梯度时，低秩代理问题的 SVD 输入是 `G^(-1/2) H(E) A^(-1/2)`。这是代理问题的精确结论，不是一般真实 H 的低秩最优解公式。
2. `GEA = H(E)` 是梯度输入与通常误差输入完全相等的充要条件。不能将其写成“一切 weighted SVD 或 QERA 有效的必要条件”；weighted SVD 总能求解自身 K 目标，两种输入即使不相等，其某个截断解也可能偶然一致。
3. 在误差 SVD 原子上，`a_H ≈ sigma, B_H ≈ I` 是使前缀收益预测准确的一组充分控制条件，不是全局最优性的保证，也不是单个前缀收益准确的必要条件。真正进入收益公式的是投影与二次收缩，误差可能相消。

“如何低成本找到并覆盖优良 correction 方向”是后续方法问题；它不妨碍先检验固定几何中的梯度输入是否有用。本轮是有理论依据的构造对照，不将结果直接命名为已完成的新 QER 方法或新颖性证明。

### 2.2 已有证据为何支持做这一步

Exp-3 及其诊断已经观察到：在原拟合经验曲率内，Full-fit 的 raw/solve 全局拟合指标都优于 Marginal，但 rank-64 补偿更差；L10 对 teacher 标签采样敏感，L31 的退化在换标签后仍存在。

这支持改查“曲率信息如何进入补偿求解”，但不证明数据已经充分或 single-Kronecker 结构无效。因此本轮固定 Marginal solve metric，不继续优化全局 Fisher 拟合。

## 3. 数学定义与两种 SVD 输入

设当前模块的量化误差为 E = W − Wq，补偿 C 的 rank 不超过 r。列向量化约定下，H 为自伴 PSD 算子，记：

\[
q_H(R)=\frac12\langle R,\mathcal H(R)\rangle_F,
\qquad M=\mathcal H(E).
\]

真实二次补偿收益满足：

\[
\Delta_H(C)=q_H(E)-q_H(E-C)
=\langle M,C\rangle_F-\frac12\langle C,\mathcal H(C)\rangle_F.
\]

固定父实验的正定 solve factors A、G，定义：

\[
\mathcal K(C)=GCA,\qquad
\mathcal T(C)=G^{1/2}CA^{1/2}.
\]

由于左右因子可逆，T 保持矩阵 rank。

**误差输入：**

\[
B_K=G^{1/2}EA^{1/2},\qquad
C_{B,r}=G^{-1/2}[B_K]_rA^{-1/2}.
\]

它精确最小化 q_K(E−C)。

**真实梯度输入：**

\[
F_K=G^{-1/2}MA^{-1/2},\qquad
C_{F,r}=G^{-1/2}[F_K]_rA^{-1/2}.
\]

它精确最小化以下低秩二次代理：

\[
m_K(C)=q_H(E)-\langle M,C\rangle_F
+\frac12\|\mathcal T(C)\|_F^2
=q_H(E)-\frac12\|F_K\|_F^2
+\frac12\|\mathcal T(C)-F_K\|_F^2.
\]

“一次 SVD”指给定 M、A、G 后的补偿构造；不包括统计、矩阵平方根与评价成本。

### 3.1 梯度输入自动满足什么

若 `F_K = sum_i s_i u_i v_i^T`，令 `D_i = G^(-1/2) u_i v_i^T A^(-1/2)`，则：

\[
\langle M,D_i\rangle_F=s_i,\qquad
\langle D_i,\mathcal K(D_j)\rangle_F=\delta_{ij}.
\]

所以直接使用 F_K 后，一阶对齐自动成立；剩余失配来自真实补偿曲率。对前缀系数 s 和真实方向 Gram 矩阵 `B_H,ij = <D_i,H(D_j)>`：

\[
\Delta_H(C_{F,r})=\|s\|_2^2-\frac12s^\top B_Hs.
\]

本轮不要求计算整个 B_H。只计算当前完整补偿方向的曲率，就可以校准幅度并检验这个构造。

### 3.2 尺度约定必须固定

沿用父实验 canonical 约定：H 已含 1/T，marginal K 已含 L/T；直接读取 solve factors，不重复乘这些系数、不再阻尼或更改 gauge。

这里有一个区别于原 weighted SVD 的性质：当 M 固定而 K 整体乘 s>0 时，C_B 不变，C_F 变成 C_F/s。因此**未校准 C_F 的幅度依赖 K 与 H 的相对尺度**。这不是结构改善，应通过冻结尺度与共同幅度校准区分。精确算术下，校准后的 C_F 对这种纯整体缩放不变。

## 4. 四个主候选与整体幅度校准

为避免与早期 KL 扰动幅度 alpha 混淆，本轮把补偿校准系数记作 beta。

对每个已有方向 C，只使用原拟合经验曲率计算：

\[
a_C=\langle M_{\rm fit},C\rangle_F,\qquad
b_C=\langle C,\widehat{\mathcal H}_{\rm fit}(C)\rangle_F.
\]

若 b_C>0，沿该方向的无约束有符号最优系数是：

\[
\beta_C^\star=\frac{a_C}{b_C},\qquad
\Delta_{\rm fit}(\beta_C^\star C)=\frac{a_C^2}{2b_C}.
\]

| 候选名 | 补偿 | 用途 |
|---|---|---|
| None | 0 | 共同损伤参照 |
| Residual-SVD | C_B | 原 Marginal weighted-SVD 构造 |
| Residual-SVD-Cal | beta_B C_B | 原方向经相同规则校准 |
| Gradient-SVD | C_F | 真实梯度低秩代理解 |
| Gradient-SVD-Cal | beta_F C_F | 梯度方向经相同规则校准 |

两组 beta 都从同一个 H_fit 得到；不在新标签或 KL 评价上重新选择。不限制 beta≤1，也不静默将其裁剪为非负。若 Residual 分支出现负 beta，完整记录其符号与含义。

对非零 C_F，有 `a_CF = ||[F_K]_r||_F² > 0`。PSD 性保证 b_CF>0，因此校准后的非零 C_F 必然降低同一个经验 q_fit；未校准 C_F 没有此保证。它不保证比校准后的 C_B 更好，也不保证独立样本、部署舍入后或真实 KL 改善。

零方向令校准补偿为 0。精确 b=0 时应有 a=0；若数值不一致则验收失败。可先把 C 按 Frobenius 范数归一化计算射线上的最优幅度，再换算 beta，避免仅因方向整体尺度过小而触发任意阈值。非有限幅度不能静默替换或裁剪。

整体标量校准不改变 rank，但只优化一条射线；校准后优于另一组不等于证明整个行/列子空间更优，更不等于全局 rank-r 最优。

## 6. 三个执行阶段

### A. 缓存构造与原经验目标核验

对 teacher-sampled 完整权重梯度 `S_ck = sum_t g_ctk x_ct^T`，沿用 sum-NLL 和 predictive Fisher 定义：

\[
\widehat{\mathcal H}_{\rm fit}(R)
=\frac1{8\cdot4\cdot T}\sum_{c=1}^8\sum_{k=1}^4
\langle S_{ck},R\rangle_FS_{ck}.
\]

1. 流式读取原 S，计算 M_fit，不构造完整 H。
2. 用同一 E、A、G 分别分解 B_K、F_K，生成四个 rank 的两个方向。
3. 在同一原 S 上计算 a_C、b_C、beta，冻结四组补偿。
4. 记录原经验 q_fit、恢复率、代理恒等式、幅度和前缀曲线。

每个样本可通过 `d_E=<S,E>`、`d_C=<S,C>` 得到：

\[
a_C=\frac1{NT}\sum d_Ed_C,\quad
b_C=\frac1{NT}\sum d_C^2,\quad
q_{\rm fit}(E-\beta C)=\frac1{2NT}\sum(d_E-\beta d_C)^2,
\quad N=32.
\]

这是构造数据上的经验结果，不作为泛化证据，不用普通训练样本 bootstrap 宣称无偏评价。

### B. 同文本、独立新标签的完整曲率评价

使用全新采样命名空间 `qer-functional-gradient-step1-v1`，base seed=2026091901；按父实验的确定性派生与采样规则登记真实标签及哈希。与原 fit 和旧 diagnosis 随机流区分，不因 token 偶然相同而拒绝样本。

每窗口 16 份新标签，共 128 份标签、256 个模块—样本记录。用同一标签计算所有候选，形成配对比较。M、factors、beta、rank 及部署张量全部先冻结。

四个 rank × 四组补偿 + None，共 17 个候选；完整记录数应为 `2×8×16×17=4352`。每个样本只做必要的共享采集，不为每个候选单独反传。

旧 diagnosis 仅保存新标签和既有候选的标量投影，未保存新 S；这些分数不能评价新 correction。即使重用旧标签，也需要重放反传。本轮选择小批全新标签，不把已有评分误当成免费新评价。

新 S 可瞬时形成或使用已验收的等价收缩，不默认永久存全部大张量；真实标签、有符号投影和归约记录必须保留。

本阶段只检查同一批文本下的新标签估计。文本已经用于构造 A/G/M，不能称为新文本泛化或完整盲测。

### C. rank-64 的实际 KL 检查

在同一 8 个 fit 窗口上，分别部署四个 rank-64 候选及 None，其他模块保持 teacher，不同时修改两个目标模块。计算 teacher 到干预模型的全词表 KL，并按相同有效位置归一化。

共 `2×8×5=80` 个模块—窗口—候选主评分，teacher 基准前向可共享。每模块在预先固定的窗口 0 对全部五候选重放一次，检查数值可重复性，不按效果挑重放窗口。

校准候选部署的是 `Wq + beta*C`，KL 在该固定模型上计算；不再乘一个额外的优化幅度。KL 不能用 sampled-label NLL 差代替。

本阶段与 B 使用同一批文本，便于比较二次目标与 actual KL 是否一致；不因此声称文本泛化。历史 validation 的大预算重放留待下一步，不自动执行。

## 7. 理想补偿与实际部署分开

理论推导及 beta 求解使用 FP64 理想低秩 C。保留其 rank-r 因子，避免用 dense FP32 舍入后的数值 rank 宣称代数 rank 恰等于 r。

部署继承父路径：先得到最终补偿（含 beta），转换为父路径规定的 FP32 表示，再形成 FP32 W_deploy；以 `R_deploy = FP64(W_teacher) − FP64(W_deploy)` 为实际残差。所有科学比较中的 q_H 与 KL 必须使用同一部署干预。

同时记录理想收益与部署收益、补偿范数及舍入漂移。下降定理只严格适用于同一个 H 下的理想补偿；若部署漂移不可忽略，报告数值问题，不重新在评价数据上校准 beta。

rank-64 Residual-SVD 应与父 Marginal-AG64 的同一 solve 构造对齐。若重算不逐位相同，检查分解、截断和部署误差；不能静默换 E、factors 或修正旧文件。

## 8. 评价量与最小诊断

统一使用每个数据阶段自身的 None 作为分母：

\[
\gamma_D(C)=1-\frac{q_D(R_C)}{q_D(E)},\qquad
\gamma_{\rm KL}(C)=1-\frac{\operatorname{KL}(C)}{\operatorname{KL}(0)}.
\]

主比较均按同 rank、同样本配对，正值表示 Gradient 更好：

\[
d_{\rm raw}=\frac{q_D(R_B)-q_D(R_F)}{q_D(E)},\qquad
d_{\rm cal}=\frac{q_D(R_{B,cal})-q_D(R_{F,cal})}{q_D(E)}.
\]

KL 用对应 None-KL 归一化，另报相对 baseline 的百分比；恢复率百分点和相对百分比不得混用。

必报的低成本诊断：

- 每个方向的 a_C、b_C、beta、q_fit、q_new、补偿 Frobenius 范数与代理预测收益。
- 原始与校准后的四条 rank—恢复率曲线；rank=64 是主对照点，其他点是预定趋势检查。
- 对 C_F，核验 `a_C = <C,K(C)> = ||[F_K]_r||_F²`；报告 `b_C / <C,K(C)>`，表示当前完整方向的真实曲率相对代理曲率。
- 对 C_B，同样报告 a_C 和 b_C 与代理值的差异。

这些标量已经足以判断整体幅度是否失配；不能由一个曲率比值反推出完整 B_H≈I，也不能区分所有对角和交叉项。完整 a_i/B_ij 诊断留到有必要解释结果时再做。

## 9. 统计与结论规则

主判定为两个模块各自 rank=64 的 raw 与 calibrated 配对比较；不只报告改善模块。

阶段 B 采用 2000 次窗口内配对 bootstrap，seed=2026091902。固定 8 个窗口，每次在各窗口内重采 16 个标签，所有方法/rank 共用索引；beta 和补偿保持冻结。区间仅描述固定文本、固定候选下新标签的采样不确定性，不覆盖构造不确定性、文本泛化或多重比较同时置信度。

沿用实际关注阈值 tau=0.02（相对 None 损伤的 2 个百分点）：95% 配对区间下界>tau 为明确且达到阈值的改善；上界<−tau 为明确退化；区间全在 [−tau,tau] 为差异较小；其他为当前预算未确定。另报是否排除零，不把“方向明确”和“幅度明确”混为一谈。

actual KL 是固定模型和文本上的确定性测量，不套用标签 bootstrap CI；报告逐窗口、总体、重放误差及同一 2pp 实际阈值。None 分母≤1e-12 时不解释归一化比值，原始损伤照常报告。恢复率不裁剪。

| 结果 | 可以说什么 |
|---|---|
| C_F 原始、校准后均优于对应 C_B，新标签与 KL 同向 | 当前固定几何下，使用真实梯度输入产生了更有效的补偿；尚非新的最优左右几何 |
| 原始 C_F 差，校准后更好 | 原始幅度失配明显；所构造补偿射线在校准后更有效，不能只据原始结果否定方向 |
| 原始更好，但两组校准后相近 | 优势可能主要来自幅度；未支持低秩方向有明确优势 |
| 仅 q_fit 改善，新标签不改善 | 原经验目标收益没有稳定迁移；保留有限样本解释 |
| 新标签 q 改善，actual KL 不改善 | 二次目标收益没有转化为本轮实际损伤收益 |
| 两组校准后 C_F 仍差 | 当前固定 K 和统计预算的梯度 SVD 构造未优于基线；不否定使用 M 或未来学习几何 |

原经验下降保证通过只能作为验收，不把它当成新方法成功。新标签和 KL 均完成后再决定下一步，不按阶段 A 的效果提前选择有利方法、模块或 rank。

## 10. 必要验收与成本边界

### 10.1 验收

1. 小矩阵显式 H 与缓存算子一致，vec/Kronecker 次序一致，收益展开式成立。
2. 取精确 H=K 的例子，验证 F_K=B_K、两组补偿一致；非零精确前缀的 beta=1。
3. 代理配方、SVD 尾能量/重构、a_CF 恒等式和校准收益恒等式通过 FP64 检查；非零 C_F 的原经验校准损伤不高于 None，并不高于同方向 beta=1 的理想损伤。
4. 保持 K 的 gauge 变化不改结果；K 单独整体缩放时，验证 C_F 与 beta 的反向变化及校准后不变性。
5. 重放父 Marginal rank-64 构造；核验同一部署残差用于 q_H 与 KL。
6. 每模块新标签首样本检查完整 S 投影与父等价收缩路径一致；样本计数、窗口等权及配对记录完整。

沿用父验收基线：根与 SVD 相对容差 1e-8，收缩容差 1e-10，部署目标相对漂移 1e-4，最大 factor condition=1e8。近零量使用明确的尺度保护分母，误差定义写入 manifest。继承父 KL 重放误差规则并记录实际数值。新梯度公式的验收不得直接套用误差 SVD 的 q_K 尾能量公式。

若失败，先定位身份/公式/数值问题，不通过隐藏增大 damping、裁剪 beta 或丢弃样本继续出科学结论。

### 10.2 成本

- 阶段 A 无模型反传，主要是原缓存读取、两种目标矩阵构造和每模块两次 dense SVD；前缀共用分解。
- 阶段 B 为 256 个模块—新样本记录，成本基于实测；不是读取旧 CSV 即可完成。候选投影应使用低秩因子或流式计算控制内存。
- 阶段 C 仅 rank-64 的前向 KL，无全词表 KL 反传。
- 不显式构造完整 H，不存大规模 B_H，不新增长期 S 缓存，不把父 9.3 GiB 缓存再复制一份。
- 后续实施可沿用 1 张 A6000、64 GiB 主机内存作为起点，先测数值与资源再冻结运行预算；不承诺未经测量的耗时，不自动扩样本或调参。

## 13. 四层全模块与双卡：运行规划补充

补充日期：2026-09-19。用户希望在资源允许时扩大到四层全模块，双卡若能有效加速则可使用。本节是成本评估与扩展规则，**尚未查询服务器实时资源、实现新实验或启动作业**；第 5 节仍记录原两模块基础方案。扩展运行须使用独立 manifest/version，不能沿用两模块的样本计数。

### 13.1 模块范围与不变项

暂按沿用历史代码层号 `model.layers.{1,10,20,31}` 估算；代码从 0 编号，若“第一层”指模型最底层，应将 1 改为 0。这只影响具体清单，不能在正式运行中混用两种编号。

每层独立检查七个 Linear：`self_attn.{q_proj,k_proj,v_proj,o_proj}` 和 `mlp.{gate_proj,up_proj,down_proj}`，共 28 个模块。这里的“全模块”不含 LayerNorm、embedding 或 lm_head；每个实验只干预一个 Linear，不能把 28 份补偿同时写入模型后当成模块级比较。

保持四组、原 8×4 构造样本、同文本 8×16 新标签、rank 前缀集合及 rank-64 KL 不变。每个新增模块按相同量化和 canonical marginal 规则生成本模块 E/A/G，四组共用；不能复用其他模块的因子。原两模块可核验后复用父资产，新增 26 个模块需要补齐统计与量化身份。

扩展后的逻辑计数为：896 个 fit 模块样本（原两模块共 64 个可复用）；3,584 个新标签模块样本；60,928 行新标签候选评分；1,120 个 rank-64 KL 主评分，另加预定重放。若实现共享反传，实际 backward 次数可能降低，但必须保持这份逻辑样本清单和数学定义。

### 13.2 耗时依据与规划区间

本地历史资源记录显示，在单张 A6000 上：

- 新标签梯度投影：L10.v_proj 平均 4.689 秒/样本，L31.q_proj 平均 2.438 秒/样本；此前两模块诊断总计约 20.02 分钟。
- 拟合样本采集含统计：两模块平均约 4.829 秒/模块样本。
- 正式 weighted-SVD 阶段：L10.v_proj 约 4.53 秒，L31.q_proj 约 20.55 秒/次；这些不是大 MLP 的测量。
- 大 MLP 的一侧 factor 为 14336×14336；其特征分解与工作区开销尚未实测，不能用小模块的耗时作等比例保证。

在沿用逐模块路径、不依赖尚未验证的共享反传加速时，代码完成后的计算规划区间为：

| 范围 | 卡数 | 规划墙钟范围 |
|---|---:|---|
| 原两个模块完整第一步 | 1 | 约 30–60 分钟 |
| 四层全部 28 模块 | 1 | 约 8–14 小时 |
| 四层全部 28 模块，独立分工 | 2 | 约 5–9 小时 |

这些是基于旧实测、新增统计、候选投影、分解和 KL 成本的预算估计，不是本轮 benchmark。双卡估计假设两张卡持续可用、模块工作量平衡且共享 CPU/磁盘不成为瓶颈；不承诺两倍加速。上述时间不含代码开发/排错、排队和重大数值故障。新 pilot 后应更新，不能保证指定起床时间前完成。

### 13.3 双卡如何使用

双卡各运行一个 worker，每个 worker 在自己的 GPU 上完成分配到的模块；无需 DDP，也不把一个模型强行拆到两卡。每个 worker 在其负责模块间复用模型和公共输入，两个 worker 共用冻结标签与配置，但分别保存结果文件。

按预计成本分配模块，兼顾浅层反传更贵及 MLP 分解更贵；不能仅按模块数量或前两层/后两层机械平分。原两个对照模块优先产出，后续覆盖按预定清单执行，不按效果选择模块。

若只有一个 worker 在做有效计算，或并行后内存/磁盘限制抵消了收益，应采用单卡方案，不能只占用第二张卡。

### 13.4 主机内存、显存和磁盘

- 沿用当前设计中的 110 GiB 任务预算时，两份 64 GiB 申请不可同时满足。双 worker 可优先评估同一租约申请两张 GPU、共 96 GiB 主机内存；这是两 worker 共享总上限，不是每人 96 GiB。是否可申请取决于实时调度余额。
- 父路径 FP32 模型在每卡约占 29.9 GiB，旧峰值约 33.9 GiB；不能把该峰值直接当作大 MLP 的上界。模型反传与大 factor 分解应分阶段，必要时卸载模型后再分解。
- 单个 14336² FP64 factor 约 1.53 GiB，根、逆根、特征向量和工作区还会增加占用。双卡不会自动合并为一个 96 GiB 显存空间。
- 全部四层的 32 份 FP64 S 若同时保留，原始张量约 208 GiB；若照抄父实现再保留逐样本 G Gram，还会增加约 442 GiB。不能默认生成这两批完整缓存。
- 新模块采用按模块流式处理：累计 marginal G，不保存逐样本 G Gram；校准确需重读 S 时，仅保留当前模块临时 S。单个大 MLP 的 32 份 S 约 14 GiB，两 worker 同时约 28 GiB，另计因素文件和输出。临时新缓存清理前保存输入标签、身份和可重建记录；不删除父缓存。
- 补偿尽量保存低秩因子，逐候选部署与评价，避免四个 rank、四种方案的全部 dense 矩阵长期同时驻留。

### 13.5 过夜执行前需要完成的短试跑

1. 数学小测试与原两模块的构造重放通过。
2. 实测一个浅层 attention 模块，以及大 MLP 的两种方向：gate/up 类型和 down 类型。两者的大 factor 分别处于输出侧与输入侧，不能只测一种就宣称全覆盖。
3. 试跑包含完整形状的 factor 根/逆根、两种 SVD、新标签投影与 KL；采样次数可少，但不得缩小矩阵形状代替内存测试。
4. 若双卡可用，再测短时间双 worker 并行的实际总内存和吞吐，以决定一张还是两张卡。只依据数值与资源选执行方式，不按效果改 rank、阻尼或模块清单。
5. 正式任务按模块 checkpoint，已通过身份核验的模块可恢复；数值失败单独报告，不覆盖其他已完成结果。达到运行预算时完整列出已完成/未完成模块，不把缺失项算成失败或补成零。
